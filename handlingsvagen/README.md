# Handlingsvågen (arbetsnamn)

**Privat tills lanseringsgrinden passerats.** Håller de vad de lovar?
Register som väger partiers och ledamöters faktiska riksdagshandlingar
— voteringar, motioner, propositioner — mot löftena och ståndpunkterna
på drygast.nu. Neutralt, regelstyrt, spårbart till dokument-id.

- Skissen och planen: `SPEC-HANDLINGSVAGEN.md`
- Neutralitetskontraktet: `NEUTRALITET.md`
- Alla metodval: `data/beslutslogg.json`
- Språkregler och kärnprinciper (ärvda från valflask): `CLAUDE.md`

Systerrepo: [bambapappa/valflask](https://github.com/bambapappa/valflask)
(drygast.nu). Vid lansering flyttas/speglas detta dit och redovisas
öppet, som allt annat.
